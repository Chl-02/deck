5.1왜 "측정 논문"인가 — 장르 결정

이 논문의 헤드라인 결과는 null result다: meta-RL과 지도학습 증류(fitted rule)는 통계적으로 구분되지 않는다(정본 n=802: 케이스 대응 t=−0.34, n=120; 구본 n=70에서는 t=+0.16으로 부호 반대). "우리 방법이 이겼다" 구조로 쓰면 게재가 성립하지 않는다. 장르를 바꾸면 같은 결과가 실패가 아니라 측정값이 된다.

5.2중심 주장 3문장

① 양산 배포를 위해 EMS 제어 권한을 bounded 9-knob calibration으로 묶으면, 무제한 제어가 얻는 연비 상금을 포기하는 대신 제약 준수를 얻는다 — 그 거래를 정량화한다.

② 그 안에서 권한·정보를 동등하게 맞추면, 학습(meta-RL)은 사람 설계 규칙을 크게 이기지만 oracle 지도 증류와 통계적으로 구분되지 않으며, 이 약 31% 천장은 특징 확장·함수 클래스· 게이팅·권한 미세조정·재적응 속도·시변 스케줄 어느 축으로도 오르지 않는다.

③ 따라서 학습의 잔여 가치는 평균 성능이 아니라 수작업 캘리브레이션의 자동화와 배포 가능한 구조(강한 base + bounded gated residual)에 있다.

⚠ 갱신 반영 (2026-07-27 → 2026-07-30 재갱신)

원래 결정록 ③은 "천장을 정하는 것은 관측 가능성이며 … (예비적으로) seed 안정성"이었다. "관측 병목" thesis는 정보 축 T0h 실험(순열 p=1.000)이 폐기했고(4장 참조), encoder 재학습 ablation(#26)으로 "예비" 딱지가 제거되면서 한때 ③은 "학습 안정성"이었다.

2026-07-30 교차검증 3축이 그 안정성 항목을 다시 정정했다. 완전 제거(z≡0) arm이 full encoder와 평균·분산 모두 구분되지 않았고(31.24/2.71 vs 30.66/2.25, 둘 다 ns), SAC → TD3 교체에서도 평균은 유지됐다(t=−1.11, ns; 단 sd 9.73). 따라서 ③의 두 번째 항은 "encoder가 사는 안정성"이 아니라 "구조 자체"로 교체했고, seed 재현성은 SAC라는 학습기 선택이 담당하는 별도 항목으로 분리된다. 집필 시 이 갱신판을 따른다 (근거: 8장 E20·E21, ledger 2026-07-30).

5.5서론 5단 구성과 기여 4개

  1. P1 — 학습 기반 HEV EMS는 큰 이득을 보고한다 (4~6%, 10%, 12.18%, 14.82%).
  2. P2 — 그러나 그 이득은 권한·정보·방법의 3중 교란이다. 문헌 자체의 문장 인용 + 리뷰 Table 1의 state 관행 + CEP 2025의 [v, acc, SOC]. 인접 연구(MPC horizon 민감도, preview 품질 연구)와 명확히 구분 — 그것들은 같은 방법 안의 튜닝이지 방법 클래스 간 정보 동등화가 아니다.
  3. P3 — 분리하려면 (a) 권한 동등화 가능한 인터페이스, (b) 도달 가능 최적 분모, (c) 무료·무오차 정보 사다리가 필요 → 본 연구가 이를 구축. DP-% 정규화는 전지적 분모라 잔여 gap을 분해하지 못함을 동기로 사용.
  4. P4 — 결과: 방법 축 ≈0 / 정보 축 ≈0 / 권한 축 지배 + 닫힌 문 9개 (gate 재설계 · 미래 예측 · 권한 확대 · 재적응 속도 · 시변 스케줄 · 표본 · 관측 집합 · 함수 클래스 · 알고리즘 계열).
  5. P5 — 기여 4개.
기여 목록 (프로토콜이 1번이어야 측정 논문이 된다)
  1. 권한 동등 평가 프로토콜 — 동일 9-knob + 에피소드별 도달가능 oracle 분모
  2. 3요인 분해 — 권한·정보를 고정하면 방법 기여 ≈0 (n=120 대응 t=−0.34, 결합 SE 1.61pt; 74배 데이터가 이득 없음)
  3. 정보 가치 곡선 — 7 arm, ECU 관측불가 반사실 포함. 정답을 줘도 오르지 않음
  4. 반증 카탈로그 9종 + 배포 가능한 산출물 (V6 + gate). ⚠ 산출물 서술은 "잠재 태스크 추론"이 아니라 구조(강한 base + bounded gated residual)로 표현할 것 — E20이 z 의존성을 반증했다

5.6그림 1 구상 — 논문 전체를 한 장으로

집필 브리프의 핵심 서사가 그대로 그림 1 스펙이다:

"권한을 바꾸면 자릿수가 바뀌고, 방법과 정보를 바꾸면 아무 일도 안 일어난다."

3개 패널 구성이 자연스럽다 — (a) 권한 축: bounded 9-knob oracle vs full power-split DP (연비 +9.3% vs 제약 위반 13배), (b) 방법 축: hand → fitted → meta-RL capture 막대 (19.5 / 31.7 / 30.7±2.3, 오차 막대는 학습 추첨 sd), (c) 정보 축: T0→T2b CV R² 평탄선과 T0h 하락 강조. 단, 권한 축 수치는 2-action 시절 산출물이 섞이지 않도록 §4의 Phase A 정합 재실행 값만 쓴다(7장 선행 작업 참조).
