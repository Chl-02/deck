3장 · 실험 연대기

22일의 기록 — thesis가 세 번 무너지고 측정 논문이 된 과정

2026-07-06부터 07-27까지, 이 프로젝트는 "meta-RL이 이긴다"를 증명하려다 실패하고, 그 실패를 체계적으로 재면서 더 강한 논문이 됐다. 이 장은 그 과정의 전체 연대기다. 왜 실험이 이렇게 설계됐는지, 왜 어떤 주장이 금지됐는지는 전부 이 역사에 이유가 있다 — 논문 §7(기각 표)과 부록의 원천이기도 하다.

세대구조운명

3.2타임라인

2026-07-06 ~ 07-09 · 2-action 시대
출발 — 개선은 있으나 너무 작다

PEARL-style encoder + SAC가 2개 knob(엔진 문턱 ±3 kW, SOC 기준 ±0.01 — wider ±5 kW/±0.02는 ablation)만 조정. 5-seed full run의 heldout 평균 개선 SOC_RMSE +0.70% — "양수지만 논문 기준 미달" 판정. robustness_v2 reward(SOC tail 중심)와 confidence gate v1(OOD 개입 저감 장치)이 이때 자리 잡음. 같은 주에 bounded DP oracle과 full-split DP diagnostic 산출 — 권한 축 데이터의 시작.

2026-07-10 ~ 07-11 · 전환점 ①
adaptive rule의 발견 — 학습이 규칙에 진다

73케이스 experiment suite에서 물리 휴리스틱 adaptive_rule_calibration이 여러 SOC tracking/tail 지표에서 meta-RL을 앞섬 — rule baseline action wrapper 버그를 수정한 뒤에도 유지. "Meta-RL이 단순 rule보다 낫다" claim 금지 결정, residual-over-rule 방향 지목. 이때부터 이 프로젝트의 기준선은 문헌 관행(약한 rule)이 아니라 강한 rule이 된다.

2026-07-12 · V2 실패
residual + DP teacher — 구조 결함으로 기각

adaptive rule 위 residual + DP teacher 모방 + SAC fine-tune. zero-offset과 gate 어댑터는 이겼지만 adaptive rule 자체를 못 이김(acceptance 미달). 원인: gate(base + residual) 구조가 base까지 감쇠 — 이후 base + gate(residual) 원칙의 유래.

2026-07-13 · 전환점 ②
headroom 정량화 — "2-action 자체가 병목"

미래를 다 아는 offline bounded DP조차 같은 2-action 권한에서는 adaptive rule 대비 SOC_RMSE headroom이 0~1%대(일부는 오히려 나쁨)임을 확인. 알고리즘 문제가 아니라 권한 문제라는 첫 구조적 결론. 당일 양산 EMS calibration knob 공개자료 조사 → 9-knob V3 action set 확정 → Simulink/FMU/Python 전면 9-action 전환까지 완료 (검증 PASS, 성능 claim은 유보).

2026-07-14 · V3 기반 다지기
물리 재정렬 + 검증 스위트 결함 수정 + Phase A 관문 통과

FASTSim 2016 Prius Two 단일 baseline으로 물리 재정렬. 논문 적합성 전체 검증에서 검증 스위트 자체의 결함 3건(허위 PASS 2건 포함) 발견·수정. 은닉 축 3종(accessory/derating/friction, 관측 격리) 구현. Phase A 정적 oracle headroom probe: 9-knob에는 headroom이 실재(high_mass_uphill 0.57) + knob 최적 방향이 조건별로 반전 → task-aware 적응 필요성 입증, Decision gate A 통과. 반면 관측 기반 9-knob rule 2종의 첫 시도는 headroom 포착 실패 (hand +6%, fitted 순손실) — "관측으로 oracle knob을 예측하기 어렵다"의 첫 신호. pilot 학습은 gate C 통과(100k에서 32.6%)했으나 200k에서 12.4%로 붕괴 — 후반 학습 OOD 과적합 발견, 체크포인트 선택 규칙 교체(tail-delta 우선 + 평활).

2026-07-15 · V3 정직한 판정
5-seed 평균 14.6% = hand 동률 — 우위 불성립

seed별 35.6 / 18.5 / 9.5 / −15.0 / 24.6% — 범위 50pt. 학습이 검증 지표를 못 움직이는 seed가 3/5. meta-RL이 이기는 곳(EMS 오보정 축)과 rule이 이기는 곳(은닉 복합 조건)이 원래 가설과 반대. 원인 7종 분해 후 "지도 신호 주입이 최대 레버" 결론 → V4로.

2026-07-17 · V4와 gate의 진실
분산은 해결, 평균은 하락 — 그리고 gate는 무죄

fitted teacher warm-start로 seed 분산 해결(범위 0.056), 그러나 평균 10.5%로 하락. "gate 감쇠가 병목" 가설을 세웠지만 gate ablation이 반증: gate off 시 4.2%로 더 나쁘고 OOD 파국(combined_hidden −0.65). gate는 유해 행동을 +6.3pt 막아주는 보호 장치 — 병목은 정책의 OOD 행동 자체.

2026-07-20 · 배선 누락의 발견
weather를 한 번도 학습한 적이 없었다 → V5

split builder가 weather_profile_index를 아예 읽지 않던 근본 원인 발견 — 그동안의 weather 전패는 일반화 실패가 아니라 학습 부재였다. 수정·재학습(V5) 후 학습 weather 3종 전부 음수→양수 전환(인과 확인), 미학습 ice는 외삽 실패(−0.51). 동시에 fitted rule도 weather-aware 재피팅으로 32.4%까지 강해져 상대 격차는 오히려 확대.

2026-07-21 · V6
결정적 성공 — 그러나 "이겼다"가 아니라 "천장에 닿았다"

base를 adaptive → fitted rule로 교체하고 정책은 ±0.3 bounded residual만. 전체 capture 9% → 32.9%(조건 단위), fitted 32.4와 나란히. ice/OOD 파국 구제 (부호 반전), seed 분산 해결(실패 seed 0, pretrain 불필요), gate의 OOD 보호와 nominal guardrail(연료 −0.81%) 유지. 직전의 전역 gate floor 스윕(P1)은 net-negative로 폐기. 이 시점의 thesis: "구조가 성능을 만든다".

2026-07-23 · 반증의 날
V7 기각 + "상회" 철회 + gate probe 기각 + 장기 프로파일

V7(anticipation): spike 프로파일 4,000개를 생성(train 2,400 / eval 1,600 seed 분리, teacher 학습은 onset 500)해 선행 대응을 학습시켰으나 격리 대조군(noantic)이 오히려 더 좋음(paired t=−3.83) — anticipation 학습이 해로움. encoder probe: z는 이력 이상으로 미래 수요를 모름(ΔR² +0.025). task-support guard만 표적 효과(high_mass_uphill +5.1pt) 성립. 유의성 검정: V6의 fitted "상회"는 모든 축에서 비유의 — "매칭"만 생존. gate 판별 probe: 어떤 특징으로도(은닉 정답 포함) gate 유불리를 판별 불가 (AUC<0.5), 사후 상한 40.4%는 선택 잡음(실질 +0.9pt). 장기 프로파일(7/14/21일): capture 우위가 일상 주행에 전이 안 됨, 정차 idle 문제(#21) 발견. 누수 검증: 교집합 0 확정 + "74배 데이터로도 선형식과 구분 불가" 재료 확보. n=301 스케일링: fitted 표본 4.3배에 R² 0.343→0.231 하락 — 표본 경로 기각. 이 시점의 thesis: "병목은 관측 가능성".

2026-07-26 · 자기 반증
정보 축 실험 — "관측 병목" thesis도 무너지다

관측 특징 사다리 7-arm(T0~T2b, n=802, 재학습 0회). 결정타 T0h: 은닉 태스크 축 4개의 정확한 값을 주었는데 CV R² 0.149→0.125 하락, 순열 p=1.000 — 완전한 태스크 지식조차 무가치. 유일하게 커 보이던 T1g(+21.6pt, Holm 유의)는 학습 80% 부분표본에서 +2.2±2.6으로 소멸 — 케이스 부트스트랩 단독의 위험이라는 방법론 교훈 (논문 §3 통계 규약으로 승격). 레버 1(재적응 속도)·레버 2(시변 스케줄)도 같은 날 기각. thesis는 최종형으로: "잔여분은 태스크의 함수가 아니라 개별 실현에 붙어 있다".

2026-07-27 · 대정리
정본 확정, 반론 봉쇄 마무리, 논문 골격 결정

하루에 아홉 건: ① fitted 정본 n=802 채택 — 부호 역전(fitted 31.7 > meta 30.7, 여전히 비유의) → "어느 쪽이 앞서는지는 학습 추첨이 정한다 = 같은 상한 수렴의 증거". ② 함수 클래스 sweep 6×5 — 상한은 선형모델 아티팩트 아님. ③ encoder 재학습 ablation — 평균 비유의, 분산 유의(sd 2.3→8.7/7.7): encoder의 기여는 안정성(확정). ④ 권한의 대가 Phase A 정합 재실행 — full-split DP 연료 +9.3% vs 제약 위반 13배. ⑤ 학습 추첨 오차 정량화(결합 SE 1.61pt). ⑥ EPA 표준 사이클 앵커링(UDDS 3.87). ⑦ 인용 검증 정정 3건 + 경쟁 문헌 4편 정독(§1 논증 수정). ⑧ ledger 전수 감사(수치 15건 전부 재현, 서술 결함 5건 교정). ⑨ 논문 범위·스토리라인 결정록 — 실험 종료 선언.

3.3thesis 변천 — 세 번의 폐기

버전주장무엇이 무너뜨렸나
v1 (07-09)"bounded adapter가 unseen 조건에서 tail risk를 줄인다"adaptive rule에 못 이겨 약화 (전환점 ①)
v2 (07-21)"구조가 성능을 만든다 — 강한 base + gated residual"07-23 유의성 검정: "상회" 철회, "매칭"만 생존
v3 (07-23)"병목은 알고리즘·권한·gate가 아니라 관측 가능성"07-26 T0h 순열 p=1.000: 정답을 줘도 안 오름 — 자기 데이터로 반증
최종 (07-26~27)"권한 동등 조건에서 모든 방법이 격차의 ~1/3에서 멈추고, 이 비율은 어떤 축에도 반응하지 않는다. 잔여분은 태스크의 함수가 아니라 개별 실현에 붙어 있어 인과적 제어의 표적이 아니다."
⚠ 집필 주의

폐기된 v1~v3 문장은 아직 구버전 문서(00_PROJECT_CONTEXT §4 일부, meta_rl_claim_positioning_ko.md, ledger 07-23 항목)에 남아 있다. 논문에 복사하지 말 것 — 7장의 문서 신뢰 순위 참조.

3.4이 연대기가 논문에 주는 것

  • 기각 실험 5종의 표(§7) — gate 재설계 / anticipation / 권한 확대 / 재적응 속도 / 시변 스케줄. 전부 "그럼 X를 해봤나"라는 심사자 반론을 실험으로 막는 클로저 증거다.
  • 방법론 교훈(§3 통계 규약) — T1g 사고(케이스 부트스트랩 단독의 위험), 체크포인트 후반 과적합, 학습 추첨 오차 병기. 사고 이력이 그대로 프로토콜 기여가 된다.
  • 자기 의심의 기록 — wrapper 버그, weather 배선 누락, --v3-config 분모 오염 2회, 검증 스위트의 허위 PASS, 전수 감사(수치 15건 재현). 이 프로젝트는 유리한 결과일수록 더 세게 의심했고, 그 절차 자체가 신뢰성 서사의 재료다.
