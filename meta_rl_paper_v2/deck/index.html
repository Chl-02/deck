1부 · 문제02 / 20

문헌의 개선폭은 서로 비교할 수 없다 — 그래서 회계가 필요하다

학습 기반 EMS 논문들은 5~20% 개선을 보고한다. 그런데 논문마다 권한(엔진 출력을 직접 제어하는가, 캘리브레이션 다이얼만 돌리는가), 정보(무엇을 관측하는가), 기준선(무엇을 이겼는가)이 전부 다르다. 같은 "+8%"라도 권한이 넓어서인지, 방법이 좋아서인지, 기준선이 약해서인지 분리되지 않는다. 최근 리뷰들도 표준 기준선과 통일 지표의 부재를 스스로 지적한다.

해법은 또 하나의 방법이 아니라 회계다 — 기준선에서 사후 최적까지의 격차를 원인별 항으로 쪼개고, 각 항을 같은 플랜트·같은 권한·같은 지표로 측정한다.

→ 다음: 그 회계 틀.

1부 · 회계 틀03 / 20

격차 G를 네 항으로 쪼갠다

G  =  A (달성분)  +  M (방법 손실)  +  O (관측 손실)  +  C (인과 손실)
측정 결과를 미리 그린 것. A·M·O는 2부에서 각각 측정되고, C는 잔여로 남는다.
항정의 (구간)묻는 질문
A기준선 → 학습 정책학습이 얼마나 먹었나
M학습 정책 → RP(같은 관측의 최적)같은 정보로 더 갈 수 있었나
ORP(관측) → RP(정보 추가)정보를 더 주면 오르나
CRP → WS(사후 최적)미래를 알아야만 먹는 몫은 얼마나 되나

용어는 확률계획법 표준(WS / RP / EEV, EVPI = WS − RP)이다. 틀은 기성품이고, 우리 것은 이 틀을 양산 캘리브레이션 층에서 학습 arm과 함께 채운 것이다.

→ 재려면 먼저 플랜트·권한·지표를 고정해야 한다. 다음 네 장.

1부 · 플랜트 ②05 / 20

EMS 결정 로직과 9노브 권한

EMS는 매 스텝 엔진을 켤지(요구 파워 vs 속도-맵 문턱 + SOC 보정, 이력 밴드, 최소 on/off 타이머)와 파워를 어떻게 나눌지(SOC 복원 항, 배터리 방전·회생 한계)를 정한다. 9노브는 이 결정식의 계수를 미세 조정하는 캘리브레이션 오프셋이다 — 학습은 엔진·모터 출력을 직접 만지지 않는다.

기능 그룹노브 (총 9)조정하는 것
G1socSOC 기준점 (±0.02) · 복원 이득SOC 목표와 복원 강도
G2thr기동 문턱 (±3 kW) · 문턱의 SOC 기울기엔진을 언제 켜나
G3cht이력 마진 · min-on (±30 s) · min-off (−5/+20 s)전환의 끈적함
G4bat방전 여유 배율 · 회생 여유 배율배터리를 얼마나 쓰나

모든 arm이 같은 9노브·같은 클램프를 통과한다. 사람 규칙, 지도 증류, meta-RL, 오라클까지 — 이 권한 동등화가 회계의 전제다. meta-RL arm(V6)은 fitted 규칙을 base로 두고 정규화 ±0.3 잔차만 내며, 신뢰 게이트가 0이면 fitted로 정확히 복귀한다.

→ 권한을 고정했다. 이제 점수를 어떻게 매기는가.

1부 · 평가 ①06 / 20

지표 J — SOC 꼬리 위험, 그리고 가드레일

주 지표 J는 SOC 조절 꼬리 위험이다 — 에피소드에서 SOC가 기준을 벗어난 정도 중 최악 구간(꼬리)을 요약한다. 배포 관점의 선택이다: 평균 성능이 아니라 최악의 순간이 배터리 수명과 주행성을 결정한다.

가드레일 — 꼬리를 다른 것으로 사면 불합격

연료증가 ≤ 0.2% — 꼬리 위험을 연료로 사는 arm 탈락
제약 위반증가 0 — 배터리·파워 한계를 파는 arm 탈락
오라클 셀가드 통과율 바닥 0.915 강제 — 분모(오라클)도 합법 제어기여야 한다

왜 절대 연비가 아닌가

플랜트 단순화(스칼라 효율, warm-start만)로 절대값은 이동하지만 모든 arm에 공통이라 순위는 보존된다. 플랜트 자체는 EPA 사이클 정합으로 검증하고(앞 장), 절대 연비 비교는 금지 항목으로 명시한다.

1부 · 평가 ②07 / 20

capture — 격차의 몇 %를 먹었는가

capture(arm) = Σi [J기준,i − Jarm,i] / Σi [J기준,i − JWS,i] × 100%

케이스 i마다 사후에 정답을 알고 9노브를 최적화한 값이 WS(분모)다. 케이스 단위 pooling이 논문 규약이고, 분모 합 5.6296은 재산출 스크립트에 assert로 박혀 있다.

평가 120케이스 (분포내 / 외삽 / 완전 held-out 3층) · fitted 학습 라벨 n=802 · meta-RL 학습 5,187 프로필

통계 규약

  • ±는 학습 추첨 sd(시드 5) — 케이스 부트스트랩은 평가 표집만 반영하므로 단독 사용 금지
  • null 결과는 "차이 없음"이 아니라 동등성 경계로 보고 (예: fitted vs meta-RL 경계 4.1pt)
  • 비교는 짝비교 — 같은 케이스·같은 시드 안에서 차이를 낸 뒤 평균

→ 자가 완성됐다. 2부: 장부를 채운다.

회계의 앞 단계 — 권한이 G 자체를 정한다

항을 재기 전에, 격차 G의 크기가 권한의 함수임을 먼저 보인다. 다이얼 9개 대신 엔진·모터 출력을 직접 제어하게 하면:

권한연비제약 위반배포
bounded 9-knob (본 연구)기준기준가능
full power-split DP+9.3%13×불가

좁은 권한은 편의가 아니라 배포 조건이 강제한 것이다. 가격표를 붙였으니, 이제 그 권한 안의 격차를 A → M → O → C 순서로 분해한다.

armcapture학습 자원
사람 손 규칙19.5%—

차이 −1.1pt = 결합 SE의 0.67배. 구분되지 않고, 어느 쪽이 앞서는지는 학습 추첨에 따라 뒤집힌다. 6,500배의 학습 자원 차이에도 같은 지점에 수렴한다 — A ≈ 31%는 방법의 속성이 아니라 그 지점의 속성이라는 첫 신호다.

→ 그 지점이 천장인가? M을 잰다.

2부 · M 방법 손실 — 논문의 심장10 / 20

M > 0 — 천장이 아니었다. 막은 것은 목적함수다

같은 99차원 선형 클래스, 같은 관측, 같은 평가. 목적함수 하나만 "오라클 노브 값 따라하기(MSE)"에서 "제어 성능 직접 최적화"로 바꿨다.

같은 클래스 · 같은 정보capture
노브 MSE 적합 (fitted)31.7%
제어 성능 직접 최적화 (시드 3)37.9% ±1.7
차이 = M+6.1pt · CI [+1.9, +10.4] · p = 0.025
양방향 구간 (샌드위치 5-fold)RP* ∈ [32.1, 39.2]

학습은 자기 천장에 못 갔고, 못 간 이유는 알고리즘이 아니다. 이론과도 맞는다 — 예측 정확도 지표(MSE)는 제어 성능과 단조 관계가 아니라는 것은 증명된 정리다. "정답 노브를 잘 맞추는 것"과 "차를 잘 모는 것"은 다른 목표다.

→ 그럼 나머지를 막는 것은? 정보인가 — O를 잰다.

2부 · O의 기전12 / 20

알아낼 값어치가 있는 축이 하나뿐이었다

은닉 축 4개를 하나씩 검사했다 — 난이도를 만드는가 · 관측에 흔적을 남기는가 · 적응하면 이득인가.

축난이도 기여관측 흔적적응 이득판정
보조부하+164.6%+1.45 kW 정확p < 0.0001진짜 축
마찰nominal 동급0.0000ns관측 불가
질량·경사−22 ~ −43%—ns오히려 쉬워짐

이 한 줄이 프로젝트의 모든 null을 설명한다 — 태스크 정답을 줘도 안 오르고(앞 장), 태스크 추론 모듈을 통째로 제거해도 무해하며, 잠재 변수가 조건 전환에 반응하지 않는다. 추론할 것이 하나뿐이었기 때문이다.

부수 교훈: 질량·경사는 "가혹한 조건"이지만 SOC 관리는 오히려 쉬워진다(엔진이 확실히 켜져 SOC가 유지된다). 난이도와 적응 가치는 별개의 양이다.

2부 · C 인과 손실13 / 20

C — 남는 것은 미래를 알아야만 먹는 몫 (EVPI)

학습 정책이 가진 "시간 가변" 능력의 값어치를 직접 쟀다.

10초마다 재결정 vs 60초 후 고정차이 ≤ 4pt
주행 중 노브 전환의 순 가치 (귀무 대조 공제 후, 600s·1800s 통합)≈ 0
유일한 생존: 관측 가능한 큰 부하 변화 (보조부하 1.05→4.0, 30분 주행)+6.8% · p=0.0001

미래를 안다면 상수 하나로 충분하다 — 목표는 궤적이 아니라 운전점 하나이고, 조건이 바뀌면 그 점이 한 번 옮겨갈 뿐이다. 유일하게 살아남은 조건이 앞 장의 유일한 진짜 축과 일치한다는 것이 이 그림의 정합성이다.

선행 인정: "예측의 한계 가치는 지수적으로 소진된다"는 이미 증명된 정리다(NeurIPS 2020). 우리 결과는 발견이 아니라 양산 권한에서의 실증이다.

2부 · 보강14 / 20

권한의 내부 구조 — 다이얼 2개가 80%를 낸다

노브를 EMS 결정식의 기능 그룹 4종으로 묶고 조합 15개를 전수 측정했다(관측 정보 고정, 시드 3).

그룹별 단독 capture %. 한계 기여(8맥락 평균)도 같은 순서: +21.5 / +8.1 / +4.8 / −0.0

SOC 기준점·복원 이득 둘만으로 전체의 80%. 엔진 기동 문턱은 단독으로는 해롭다. 실무 언어로 바로 읽힌다 — 어느 캘리브레이션 기능을 여는 것이 값어치 있는가.

잠정 — 포함관계 감사에서 위반 5건(넓은 조합의 탐색 부족). 재측정 진행 중이며, 통과 전에는 권한을 가로지르는 결론을 쓰지 않는다.

→ 장부가 채워졌다. 3부: 논문으로 조립한다.

3부 · 방법 기여15 / 20
